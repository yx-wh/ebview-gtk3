5.5 Selecting Text
　


When you select a range of text in the displayed content with the mouse, the selection is stored in the X selection and can be pasted into other applications.

Pressing the right mouse button pops up a menu. Choosing [Search This Word] performs a search using the selected word as the search term. Choosing [Copy To Clipboard] copies the selected text to the clipboard, which can then be pasted into other applications with Ctrl + v, etc. (depending on the application).

In addition, when text is selected in the content area, pressing the Enter key immediately performs a search using the selected text as the search term — the same as choosing [Search This Word].
